⚙️ Algoritmos

Big O Notation — Medir Eficiência

Big O descreve como o tempo de execução cresce conforme o tamanho da entrada (n) cresce. É a forma padrão de comparar algoritmos independentemente de hardware.

Pense assim: Se seu algoritmo leva 1 segundo para 100 itens, quanto levaria para 1 milhão? A resposta depende do Big O.

Algoritmos de Busca

Busca Linear — O(n)

Percorre cada elemento um por um. Funciona em listas não ordenadas. Para grandes datasets, é lento.

def busca_linear(lista, alvo): """Retorna o índice do alvo ou -1 se não encontrado.""" for i, item in enumerate(lista): if item == alvo: return i # ✅ encontrado na posição i return -1 # ❌ não encontrado numeros = [64, 34, 25, 12, 22, 11, 90] print(busca_linear(numeros, 22)) # 4 (índice 4) print(busca_linear(numeros, 99)) # -1 (não existe)

Busca Binária — O(log n)

Requer lista ordenada. Divide pela metade a cada passo. 1 bilhão de elementos = ~30 comparações!

def busca_binaria(lista, alvo): inicio, fim = 0, len(lista) - 1 while inicio <= fim: meio = (inicio + fim) // 2 if lista[meio] == alvo: return meio # ✅ achou elif lista[meio] < alvo: inicio = meio + 1 # vai para direita else: fim = meio - 1 # vai para esquerda return -1 ordenada = [2, 5, 8, 12, 16, 23, 38, 56, 72, 91] print(busca_binaria(ordenada, 23)) # 5

Algoritmos de Ordenação

Bubble Sort — O(n²)

Compara pares adjacentes e troca se estiver fora de ordem. Simples de entender, mas ineficiente para grandes volumes.

def bubble_sort(lista): n = len(lista) for i in range(n): for j in range(0, n - i - 1): if lista[j] > lista[j + 1]: lista[j], lista[j+1] = lista[j+1], lista[j] # troca return lista print(bubble_sort([64, 34, 25, 12, 22])) # [12, 22, 25, 34, 64]

Merge Sort — O(n log n)

Divide a lista ao meio recursivamente, ordena cada metade e mescla. Muito mais eficiente para grandes volumes.

def merge_sort(lista): if len(lista) <= 1: return lista # caso base: lista de 1 elemento já está ordenada meio = len(lista) // 2 esquerda = merge_sort(lista[:meio]) # ordena metade esquerda direita = merge_sort(lista[meio:]) # ordena metade direita return _mesclar(esquerda, direita) # mescla as duas def _mesclar(a, b): resultado = [] i = j = 0 while i < len(a) and j < len(b): if a[i] <= b[j]: resultado.append(a[i]); i += 1 else: resultado.append(b[j]); j += 1 return resultado + a[i:] + b[j:]

Recursão

Recursão é quando uma função chama a si mesma para resolver versões menores do mesmo problema. Todo algoritmo recursivo precisa de um caso base (condição de parada) para não entrar em loop infinito.

# Fatorial: 5! = 5 × 4 × 3 × 2 × 1 = 120 def fatorial(n): if n == 0 or n == 1: # caso base return 1 return n * fatorial(n - 1) # chamada recursiva print(fatorial(5)) # 120 print(fatorial(10)) # 3628800 # Fibonacci: 0,1,1,2,3,5,8,13,21... def fib(n): if n <= 1: return n return fib(n-1) + fib(n-2)
