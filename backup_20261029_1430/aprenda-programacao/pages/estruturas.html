🗂️ Estruturas de Dados

Formas de organizar, armazenar e gerenciar dados na memória. Escolher a estrutura certa é a diferença entre um programa rápido e um lento, entre um código elegante e um confuso.

Módulo 3 Arrays & Listas Pilhas & Filas Árvores & Grafos
1

Array (Vetor / Lista)

Coleção ordenada de elementos do mesmo tipo armazenados em posições contíguas de memória. A estrutura mais fundamental da computação.

✅ Pontos fortes

Acesso por índice O(1) — instantâneo. Iteração sequencial eficiente. Simples de usar.

⚠️ Limitações

Inserção/remoção no meio O(n) — precisa deslocar elementos. Tamanho fixo em C/Java.

# Arrays / Listas em Python numeros = [10, 20, 30, 40, 50] # Acesso O(1) print(numeros[0]) # 10 — primeiro elemento print(numeros[-1]) # 50 — último elemento print(numeros[1:3]) # [20, 30] — fatiamento (slice) # Operações numeros.append(60) # adiciona no final — O(1) numeros.insert(2, 99) # insere na posição 2 — O(n) numeros.remove(99) # remove por valor — O(n) print(len(numeros)) # tamanho da lista print(sorted(numeros)) # retorna nova lista ordenada
2

Pilha (Stack) — LIFO

Regra LIFO — Last In, First Out (último que entra, primeiro que sai). Como uma pilha de pratos — você só pode adicionar ou retirar do topo.

Operações: push (empilhar) — O(1)  |  pop (desempilhar) — O(1)  |  peek (ver o topo sem remover) — O(1)

class Pilha: def __init__(self): self._dados = [] def push(self, valor): self._dados.append(valor) def pop(self): if self.vazia(): raise IndexError("Pilha vazia") return self._dados.pop() def peek(self): return self._dados[-1] if self._dados else None def vazia(self): return len(self._dados) == 0 p = Pilha() p.push("A"); p.push("B"); p.push("C") print(p.pop()) # "C" — último que entrou, primeiro que sai print(p.peek()) # "B" — vê o topo sem remover
Usos reais: Ctrl+Z (desfazer) em editores, call stack de funções, navegação de browsers (botão Voltar), avaliação de expressões matemáticas, parsers de HTML/XML.
3

Fila (Queue) — FIFO

Regra FIFO — First In, First Out (primeiro que entra, primeiro que sai). Como uma fila de banco — quem chegou primeiro, sai primeiro.

from collections import deque # deque é otimizado para filas fila = deque() fila.append("Cliente 1") # enqueue — entra no final fila.append("Cliente 2") fila.append("Cliente 3") print(fila.popleft()) # "Cliente 1" — dequeue — sai do início print(fila.popleft()) # "Cliente 2"
Usos reais: Filas de impressão, processamento de mensagens (RabbitMQ, Kafka), sistema de atendimento, BFS em grafos.
4

Hash Table (Dicionário / Map)

Armazena pares chave → valor. Internamente usa uma função hash para converter a chave em um índice de array. Busca, inserção e remoção são O(1) na média.

# Dicionário em Python (implementação de Hash Table) usuario = { "nome": "Ana", "email": "ana@email.com", "idade": 28, "ativo": True } print(usuario["nome"]) # "Ana" — O(1)! usuario["cidade"] = "SP" # adicionar nova chave del usuario["ativo"] # remover chave print("email" in usuario) # True — verificar existência # Contar frequência de palavras texto = "ana banana ana laranja banana ana" freq = {} for palavra in texto.split(): freq[palavra] = freq.get(palavra, 0) + 1 print(freq) # {'ana': 3, 'banana': 2, 'laranja': 1}
Usos reais: Caches, sessões de usuário, contagem de frequência, índices de banco de dados, JSON é um hash table, objetos em JavaScript.
5

Árvore (Tree)

Estrutura hierárquica com um nó raiz e filhos. A Árvore Binária de Busca (BST) garante que todos os filhos esquerdos são menores e todos os filhos direitos são maiores que o nó pai.

OperaçãoBST BalanceadaBST Pior caso
BuscaO(log n)O(n)
InserçãoO(log n)O(n)
RemoçãoO(log n)O(n)
Usos reais: Sistemas de arquivos (pasta dentro de pasta), DOM do HTML, índices B-Tree de bancos de dados, árvores de decisão em IA, compiladores (AST).
6

Grafo (Graph)

Conjunto de vértices (nós) conectados por arestas. A estrutura mais geral e poderosa. Todo o mundo conectado pode ser modelado como um grafo.

TipoDescriçãoExemplo
Não-direcionadoArestas sem direção (bidirecionais)Amizades no Facebook
DirecionadoArestas com seta (seguem uma direção)Follows no Twitter/X
PonderadoArestas com peso/custoDistâncias em mapas GPS
# Grafo como lista de adjacência grafo = { "A": ["B", "C"], "B": ["A", "D"], "C": ["A", "D"], "D": ["B", "C"] } # BFS — Busca em Largura (explora vizinhos antes de ir fundo) from collections import deque def bfs(grafo, inicio): visitados = set() fila = deque([inicio]) while fila: no = fila.popleft() if no not in visitados: print(no) visitados.add(no) fila.extend(grafo[no])
Usos reais: Redes sociais, GPS e navegação (Dijkstra), internet (roteamento de pacotes), sistemas de recomendação, detecção de fraudes.
