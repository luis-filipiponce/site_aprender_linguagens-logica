📜 História & Evolução

1994
PHP/FI — Personal Home Page / Forms Interpreter
Rasmus Lerdorf cria scripts em C para rastrear visitas ao seu currículo online. Nasce o conceito de server-side scripting embutido em HTML.
1997
PHP 3 — Reescrita total
Zeev Suraski e Andi Gutmans reescrevem o interpretador do zero. PHP 3 se torna a base de grande parte da web inicial, com suporte a bancos de dados e extensibilidade real.
2000
PHP 4 — Zend Engine 1.0
Introdução do Zend Engine, melhorias de performance massivas e suporte a sessões. PHP explode em popularidade com a Web 1.0.
2004
PHP 5 — Zend Engine 2, POO real, PDO
Orientação a Objetos madura (interfaces, abstract classes, __autoload), PDO para banco de dados, exceptions, SimpleXML. Surgem Symfony e Zend Framework.
2015
PHP 7 — Zend Engine 3, 2× mais rápido
Performance dobrada em relação ao PHP 5.6, tipos escalares declaráveis, return types, operador spaceship (<=>), ?? null coalescing. PHP volta ao centro das atenções.
2020
PHP 8.0 — JIT, Named Arguments, Match, Union Types
Compilação JIT (Just-In-Time) para workloads computacionais, Named Arguments, Match expression sem fall-through, Union Types, Nullsafe operator ?->.
2022
PHP 8.2 — Readonly Classes, DNF Types
Classes readonly completas, Disjunctive Normal Form (DNF) types, null e false como standalone types. Fibras (Fibers) introduzidas no 8.1 ganham maturidade.
2023
PHP 8.3 — Typed class constants, json_validate()
Constantes de classe tipadas, json_validate(), melhorias em #[Override] attribute, randomização aprimorada com a nova classe Randomizer.
2024
PHP 8.4 — Property Hooks, Asymmetric Visibility
Property Hooks permitem lógica get/set inline em propriedades de classe, Asymmetric Visibility (public private(set)), array_find(), lazy objects e melhorias no DOM.

🧠 Conceitos Fundamentais

PHP usa tipagem dinâmica por padrão. Com declare(strict_types=1) você ativa tipagem estrita em type hints, garantindo que erros de tipo sejam capturados em tempo de execução.

<?php
declare(strict_types=1);

// Tipos primitivos
$nome   = "PHP";          // string
$versao = 8.4;           // float
$ativo  = true;          // bool
$qtd    = 1000;          // int

// Array associativo
$config = [
    'host' => 'localhost',
    'port' => 3306,
];

// Nullsafe operator (PHP 8+)
$user  = getUser(1);
$email = $user?->profile?->email ?? 'sem e-mail';

// Match expression
$label = match(true) {
    $versao >= 8.0 => 'Moderno',
    $versao >= 7.0 => 'Atual',
    default         => 'Legado',
};

PHP disponibiliza variáveis superglobais que estão acessíveis em qualquer escopo: $_GET, $_POST, $_SESSION, $_COOKIE, $_SERVER e $_FILES.

<?php
session_start();

// Leitura segura de $_GET
$id = filter_input(INPUT_GET, 'id', FILTER_VALIDATE_INT);

// POST com sanitização

    trim($_POST['nome'] ?? '')

// Sessão de autenticação

// Cookie com 7 dias

// Informações do servidor

PDO (PHP Data Objects) oferece uma interface unificada para múltiplos bancos de dados. Use sempre Prepared Statements para prevenir SQL Injection.

<?php
$dsn = 'mysql:host=localhost;dbname=app;charset=utf8mb4';
$pdo = new PDO($dsn, 'root', 'secret', [
    PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
]);

// SELECT com prepared statement
$stmt = $pdo->prepare('SELECT * FROM users WHERE email = :email');
$stmt->execute([':email' => $email]);
$user = $stmt->fetch();

// INSERT
$stmt = $pdo->prepare(
    'INSERT INTO users (name, email, password) VALUES (?, ?, ?)'
);
$stmt->execute([$name, $email, password_hash($pass, PASSWORD_BCRYPT)]);

PHP suporta POO completa: classes, interfaces, traits, classes abstratas, herança, polimorfismo, encapsulamento e PHP 8.1+ enums e fibras.

<?php
interface Notifiable {
    public function notify(string $msg): void;
}

trait HasTimestamps {
    public readonly \DateTimeImmutable $createdAt;

    public function initTimestamps(): void {
        $this->createdAt = new \DateTimeImmutable();
    }
}

abstract class BaseUser implements Notifiable {
    use HasTimestamps;

    public function __construct(
        protected readonly int    $id,
        protected          string $name,
    ) { $this->initTimestamps(); }

    abstract public function role(): string;
}

class Admin extends BaseUser {
    public function role(): string { return 'admin'; }
    public function notify(string $msg): void {
        mail('admin@app.com', 'Alert', $msg);
    }
}

PHP moderno usa exceptions e tipos de erro estruturados. Crie exceptions customizadas, use finally e configure um handler global com set_exception_handler().

<?php
class NotFoundException extends \RuntimeException {
    public function __construct(string $resource, int $id) {
        parent::__construct("$resource #$id não encontrado", 404);
    }
}

function findUser(int $id): array {
    $user = fetchFromDb($id);
    if (!$user) throw new NotFoundException('User', $id);
    return $user;
}

try {
    $user = findUser(99);
} catch (NotFoundException $e) {
    http_response_code($e->getCode());
    echo json_encode(['error' => $e->getMessage()]);
} finally {
    // Sempre executado — fechar conexão, liberar recurso
    closeDb();
}

💻 Exemplos Práticos

API REST completa em PHP puro com PDO — suporte a GET, POST, PUT e DELETE, retornando respostas JSON padronizadas.

<?php
declare(strict_types=1);

header('Content-Type: application/json; charset=utf-8');
header('Access-Control-Allow-Origin: *');

$pdo = new PDO('mysql:host=localhost;dbname=api;charset=utf8mb4', 'root', '', [
    PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
]);

$method = $_SERVER['REQUEST_METHOD'];
$id     = filter_input(INPUT_GET, 'id', FILTER_VALIDATE_INT);

function respond(mixed $data, int $code = 200): never {
    http_response_code($code);
    echo json_encode($data, JSON_UNESCAPED_UNICODE);
    exit;
}

match($method) {

    'GET' => function() use ($pdo, $id) {
        if ($id) {
            $st = $pdo->prepare('SELECT * FROM products WHERE id = ?');
            $st->execute([$id]);
            $product = $st->fetch();
            $product ? respond($product) : respond(['error' => 'Not Found'], 404);
        }
        $st = $pdo->query('SELECT * FROM products ORDER BY id DESC LIMIT 50');
        respond(['data' => $st->fetchAll(), 'total' => $st->rowCount()]);
    },

    'POST' => function() use ($pdo) {
        $body = json_decode(file_get_contents('php://input'), true);
        if (empty($body['name']) || !isset($body['price'])) {
            respond(['error' => 'name e price são obrigatórios'], 422);
        }
        $st = $pdo->prepare('INSERT INTO products (name, price) VALUES (?, ?)');
        $st->execute([$body['name'], (float)$body['price']]);
        respond(['id' => $pdo->lastInsertId(), 'message' => 'Criado com sucesso'], 201);
    },

    'PUT' => function() use ($pdo, $id) {
        if (!$id) respond(['error' => 'ID obrigatório'], 400);
        $body = json_decode(file_get_contents('php://input'), true);
        $st   = $pdo->prepare('UPDATE products SET name=?, price=? WHERE id=?');
        $st->execute([$body['name'], (float)$body['price'], $id]);
        respond(['updated' => $st->rowCount()]);
    },

    'DELETE' => function() use ($pdo, $id) {
        if (!$id) respond(['error' => 'ID obrigatório'], 400);
        $st = $pdo->prepare('DELETE FROM products WHERE id = ?');
        $st->execute([$id]);
        respond(['deleted' => $st->rowCount()]);
    },

    default => respond(['error' => 'Method Not Allowed'], 405),
}();

Controller Laravel completo com Eloquent ORM, validação de formulário via FormRequest e retorno JSON para API.

<?php
namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Http\Requests\StoreProductRequest;
use App\Models\Product;
use Illuminate\Http\JsonResponse;

class ProductController extends Controller
{
    public function index(): JsonResponse
    {
        $products = Product::with('category')
            ->where('active', true)
            ->orderByDesc('created_at')
            ->paginate(15);

        return response()->json($products);
    }

    public function store(StoreProductRequest $request): JsonResponse
    {
        $product = Product::create($request->validated());

        return response()->json($product->load('category'), 201);
    }

    public function show(Product $product): JsonResponse
    {
        return response()->json($product->load(['category', 'reviews']));
    }

    public function update(StoreProductRequest $request, Product $product): JsonResponse
    {
        $product->update($request->validated());
        return response()->json($product->fresh());
    }

    public function destroy(Product $product): JsonResponse
    {
        $product->delete();
        return response()->json(null, 204);
    }
}

// FormRequest — validação centralizada
class StoreProductRequest extends FormRequest
{
    public function authorize(): bool { return $this->user()?->can('manage-products') ?? false; }

    public function rules(): array
    {
        return [
            'name'        => ['required', 'string', 'max:120'],
            'price'       => ['required', 'numeric', 'min:0'],
            'category_id' => ['required', 'exists:categories,id'],
            'active'      => ['boolean'],
        ];
    }
}

// Model com relacionamentos
class Product extends Model
{
    protected $fillable = ['name', 'price', 'category_id', 'active'];
    protected function casts(): array { return ['price' => 'float', 'active' => 'boolean']; }

    public function category() { return $this->belongsTo(Category::class); }
    public function reviews()  { return $this->hasMany(Review::class); }
}

Sistema de autenticação seguro com sessions, password_hash() / password_verify(), proteção CSRF e renovação de session ID.

<?php
declare(strict_types=1);

session_start();

// ── Configuração de cookies de sessão segura ──────────────────
session_set_cookie_params([
    'lifetime' => 0,
    'path'     => '/',
    'secure'   => true,
    'httponly' => true,
    'samesite' => 'Strict',
]);

// ── CSRF Token ─────────────────────────────────────────────────
function csrfToken(): string {
    if (empty($_SESSION['csrf_token'])) {
        $_SESSION['csrf_token'] = bin2hex(random_bytes(32));
    }
    return $_SESSION['csrf_token'];
}

function validateCsrf(string $token): bool {
    return hash_equals($_SESSION['csrf_token'] ?? '', $token);
}

// ── Registro ───────────────────────────────────────────────────
function register(PDO $pdo, string $email, string $password): int {
    if (strlen($password) < 8) {
        throw new \InvalidArgumentException('Senha muito curta');
    }
    $hash = password_hash($password, PASSWORD_ARGON2ID, [
        'memory_cost' => 65536,
        'time_cost'   => 4,
        'threads'     => 1,
    ]);
    $st = $pdo->prepare('INSERT INTO users (email, password) VALUES (?, ?)');
    $st->execute([$email, $hash]);
    return (int)$pdo->lastInsertId();
}

// ── Login ──────────────────────────────────────────────────────
function login(PDO $pdo, string $email, string $password): bool {
    $st = $pdo->prepare('SELECT id, password, role FROM users WHERE email = ?');
    $st->execute([$email]);
    $user = $st->fetch();

    if (!$user || !password_verify($password, $user['password'])) {
        return false;
    }

    // Regenerar ID de sessão — previne Session Fixation
    session_regenerate_id(true);

    $_SESSION['user_id'] = $user['id'];
    $_SESSION['role']    = $user['role'];
    $_SESSION['login_at'] = time();

    // Rehash se algoritmo mais forte disponível
    if (password_needs_rehash($user['password'], PASSWORD_ARGON2ID)) {
        $st = $pdo->prepare('UPDATE users SET password=? WHERE id=?');
        $st->execute([password_hash($password, PASSWORD_ARGON2ID), $user['id']]);
    }
    return true;
}

// ── Middleware de Autenticação ──────────────────────────────────
function requireAuth(string ...$roles): void {
    if (empty($_SESSION['user_id'])) {
        http_response_code(401);
        echo json_encode(['error' => 'Não autenticado']);
        exit;
    }
    if (!empty($roles) && !in_array($_SESSION['role'], $roles, true)) {
        http_response_code(403);
        echo json_encode(['error' => 'Sem permissão']);
        exit;
    }
}

// Uso:
requireAuth('admin', 'editor');
