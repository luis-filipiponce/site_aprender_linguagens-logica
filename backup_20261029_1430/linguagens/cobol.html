Destaque Histórico: Grace Hopper & o CODASYL

A contra-almirante Grace Murray Hopper defendia que programas deveriam ser escritos em uma linguagem próxima ao inglês comum, e não apenas em código de máquina ou assembly. Sua criação, o FLOW-MATIC (1955), serviu de alicerce para o comitê CODASYL (Conference on Data Systems Languages) que em 1959 concebeu o COBOL. Grace Hopper também popularizou o termo “bug” e construiu os primeiros compiladores da história.

1959

COBOL 1.0 (CODASYL)

Criação da primeira especificação oficial com foco empresarial, legibilidade em inglês e suporte nativo a registros de dados e cálculos contábeis.

1968

COBOL-68 ANSI Standard

Primeira padronização oficial pelo comitê ANSI, garantindo portabilidade entre diferentes fabricantes de hardware da época.

1974

COBOL-74

Adição de organização de arquivos sequenciais indexados (ISAM), instrução CALL para subprogramas e manipulação avançada de tabelas.

1985

COBOL-85 Marco Estruturado

Revolução da programação estruturada na linguagem: delimitadores explícitos de escopo (END-IF, END-PERFORM, END-READ), comando EVALUATE (switch/case) e subprogramas aninhados.

1997

COBOL-97

Adoção de programação orientada a objetos preliminar, ponte com bancos de dados relacionais e preparação dos sistemas para o Bug do Milênio (Y2K).

2002

COBOL 2002 ISO/IEC Standard

Suporte completo a Orientação a Objetos (classes, métodos, interfaces), suporte a Unicode, formatação livre de colunas (free-format) e tipos de ponto flutuante.

2014

COBOL 2014

Padronização ISO modernizada com suporte nativo a tabelas dinâmicas, manipulação de strings com capacidade estendida e interoperabilidade nativa com C e Java.

2023

COBOL 2023 & Enterprise COBOL 6.4+

Integração nativa com Cloud Híbrida, parsing nativo de JSON e XML, chamadas a APIs REST via z/OS Connect, aceleração por hardware z16 (IA) e compatibilidade com microsserviços.

Todo programa COBOL clássico é rigorosamente organizado em 4 divisões hierárquicas que separam metadados, ambiente operacional, definição de variáveis e a lógica de execução:

  • IDENTIFICATION DIVISION: Nome do programa, autor, data e documentação.
  • ENVIRONMENT DIVISION: Associação de arquivos lógicos a dispositivos físicos (Mainframe/Disco).
  • DATA DIVISION: Declaração de variáveis de memória de trabalho e layouts de arquivo.
  • PROCEDURE DIVISION: Onde residem os comandos, laços, regras de negócio e fluxo do programa.

Em COBOL não existem tipos genéricos dinâmicos; cada campo tem um formato e tamanho explícito em bytes via cláusula PICTURE (ou PIC). A hierarquia de dados usa números de nível (01 a 49, 77 para variáveis soltas):

  • PIC X(n): Alfanumérico (texto, caracteres gerais).
  • PIC 9(n): Numérico inteiro sem sinal.
  • PIC S9(n)V99: Numérico com sinal (S) e ponto decimal implícito (V).
  • COMP-3: Formato Decimal Compactado (Packed Decimal), padrão no mundo financeiro para otimizar espaço e precisão de centavos.
  • PIC ZZ.ZZ9,99: Máscara de edição para relatórios visuais formatados.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       *> Variavel de grupo (estrutura tipo Struct)
       01  WS-CLIENTE.
           05  WS-ID-CLIENTE    PIC 9(06)       VALUE 104523.
           05  WS-NOME-CLIENTE  PIC X(40)       VALUE "MARIA CLARA SILVA".
           05  WS-SALDO         PIC S9(09)V99   COMP-3 VALUE 15450.75.
           05  WS-STATUS-CONTA  PIC X(01)       VALUE "A".
       
       *> Campo de edicao para relatorio impresso
       01  WS-SALDO-FORMATADO   PIC R$*.***.**9,99.

       PROCEDURE DIVISION.
           MOVE WS-SALDO TO WS-SALDO-FORMATADO
           DISPLAY "Cliente: " WS-NOME-CLIENTE
           DISPLAY "Saldo Formatado: " WS-SALDO-FORMATADO.

O comando PERFORM é o pilar da modularização e repetição em COBOL. Ele pode executar parágrafos isolados (semelhante a funções sem retorno direto), repetir blocos UNTIL (condição) ou variar contadores com VARYING ... FROM ... BY.

       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01  WS-CONTADOR          PIC 9(03) VALUE 0.
       01  WS-TOTAL-ACUMULADO   PIC 9(05) VALUE 0.

       PROCEDURE DIVISION.
       0000-INICIO.
           DISPLAY "INICIANDO PROCESSAMENTO MODULAR"
           PERFORM 1000-PROCESSAR-LOTE
               VARYING WS-CONTADOR FROM 1 BY 1
               UNTIL WS-CONTADOR > 5
           
           DISPLAY "TOTAL FINAL: " WS-TOTAL-ACUMULADO
           STOP RUN.

       1000-PROCESSAR-LOTE.
           ADD 100 TO WS-TOTAL-ACUMULADO
           DISPLAY "Iteracao: " WS-CONTADOR 
                   " | Subtotal: " WS-TOTAL-ACUMULADO.

O coração do processamento batch no Mainframe. Conecta arquivos físicos por meio de SELECT ... ASSIGN na ENVIRONMENT DIVISION, mapeia registros com FD (File Description) e consome linha a linha usando OPEN, READ ... AT END e CLOSE.

       ENVIRONMENT DIVISION.
       INPUT-OUTPUT SECTION.
       FILE-CONTROL.
           SELECT ARQ-TRANS ASSIGN TO "TRANS.DAT"
           ORGANIZATION IS LINE SEQUENTIAL
           FILE STATUS IS WS-FS-TRANS.

       DATA DIVISION.
       FILE SECTION.
       FD  ARQ-TRANS.
       01  REG-TRANS.
           05  NUM-CONTA        PIC 9(08).
           05  VALOR-TRANS      PIC 9(06)V99.

       WORKING-STORAGE SECTION.
       01  WS-FS-TRANS          PIC X(02).
       01  WS-EOF               PIC X(01) VALUE "N".

       PROCEDURE DIVISION.
           OPEN INPUT ARQ-TRANS
           IF WS-FS-TRANS NOT = "00"
               DISPLAY "ERRO AO ABRIR ARQUIVO: " WS-FS-TRANS
               STOP RUN
           END-IF

           PERFORM UNTIL WS-EOF = "S"
               READ ARQ-TRANS
                   AT END
                       MOVE "S" TO WS-EOF
                   NOT AT END
                       DISPLAY "Conta: " NUM-CONTA " | Valor: " VALOR-TRANS
               END-READ
           END-PERFORM

           CLOSE ARQ-TRANS.

O Nível 88 é uma das características mais elegantes do COBOL: ele associa nomes semânticos (valores booleanos) a estados de uma variável pai. Ao invés de checar códigos misteriosos como IF STATUS = 'A', você programa em linguagem humana e expressiva.

       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01  WS-STATUS-CLIENTE    PIC X(01).
           88  CONTA-ATIVA      VALUE "A".
           88  CONTA-BLOQUEADA  VALUE "B".
           88  CONTA-ENCERRADA  VALUE "E".
           88  CONTA-VALIDA     VALUES ARE "A" "B".

       PROCEDURE DIVISION.
           *> Atribuindo diretamente via condicao booleana
           SET CONTA-ATIVA TO TRUE

           *> Lendo expressivamente
           IF CONTA-ATIVA
               DISPLAY "Acesso liberado para operacoes de credito."
           ELSE
               DISPLAY "Transacao nao autorizada pelo sistema central."
           END-IF.

Diferente de linguagens como C ou Java que usam float binário (sujeito a erros de arredondamento em centavos), o COBOL opera com aritmética decimal de ponto fixo. O comando COMPUTE permite fórmulas algébricas completas com cláusulas essenciais como ROUNDED e ON SIZE ERROR (proteção contra estouro de campo).

       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01  WS-CAPITAL           PIC 9(07)V99 VALUE 50000.00.
       01  WS-TAXA-MENSAL       PIC 9(02)V9999 VALUE 0.0175. *> 1.75% a.m.
       01  WS-MESES             PIC 9(03)    VALUE 12.
       01  WS-JUROS             PIC 9(07)V99.
       01  WS-MONTANTE          PIC 9(08)V99.

       PROCEDURE DIVISION.
           *> Formula financeira com tratamento de arredondamento e estouro
           COMPUTE WS-JUROS ROUNDED = 
                   WS-CAPITAL * WS-TAXA-MENSAL * WS-MESES
               ON SIZE ERROR
                   DISPLAY "CRITICO: Estouro de capacidade numerica!"
               NOT ON SIZE ERROR
                   ADD WS-CAPITAL TO WS-JUROS GIVING WS-MONTANTE
                   DISPLAY "Juros: R$ " WS-JUROS
                   DISPLAY "Montante Final: R$ " WS-MONTANTE
           END-COMPUTE.

Cálculo contábil completo de salário bruto, desconto progressivo de INSS, dedução de IRRF, vale-transporte e emissão de holerite formatado.

       IDENTIFICATION DIVISION.
       PROGRAM-ID. FOLHA01.
       AUTHOR. PONCE METODOLOGIAS & DEV.
      *>==============================================================*
       ENVIRONMENT DIVISION.
       CONFIGURATION SECTION.
       SPECIAL-NAMES.
           DECIMAL-POINT IS COMMA.
      *>==============================================================*
       DATA DIVISION.
       WORKING-STORAGE SECTION.
      *> DADOS DE ENTRADA DO FUNCIONARIO
       01  WS-MATRICULA         PIC 9(06)       VALUE 084512.
       01  WS-NOME              PIC X(30)       VALUE "CARLOS EDUARDO SILVEIRA".
       01  WS-CARGO             PIC X(25)       VALUE "ESPECIALISTA MAINFRAME".
       01  WS-SALARIO-BRUTO     PIC 9(06)V99    VALUE 14500.00.
       01  WS-NUM-DEPENDENTES   PIC 9(02)       VALUE 02.

      *> CAMPOS DE CALCULO E DEDUCOES
       01  WS-DESC-INSS         PIC 9(05)V99    VALUE 0.
       01  WS-BASE-IRRF         PIC 9(06)V99    VALUE 0.
       01  WS-DESC-IRRF         PIC 9(05)V99    VALUE 0.
       01  WS-DED-DEPENDENTE    PIC 9(04)V99    VALUE 189.59.
       01  WS-TOTAL-DED-DEP     PIC 9(05)V99    VALUE 0.
       01  WS-SALARIO-LIQUIDO   PIC 9(06)V99    VALUE 0.

      *> MASCARAS DE EDICAO PARA EXIBICAO FORMATADA
       01  WS-ED-BRUTO          PIC R$**.**9,99.
       01  WS-ED-INSS           PIC R$**.**9,99.
       01  WS-ED-IRRF           PIC R$**.**9,99.
       01  WS-ED-LIQUIDO        PIC R$**.**9,99.

      *>==============================================================*
       PROCEDURE DIVISION.
       0000-PRINCIPAL.
           PERFORM 1000-CALCULAR-INSS
           PERFORM 2000-CALCULAR-IRRF
           PERFORM 3000-CALCULAR-LIQUIDO
           PERFORM 4000-EMITIR-HOLERITE
           STOP RUN.

       1000-CALCULAR-INSS.
      *> Teto maximo de contribuicao do INSS
           IF WS-SALARIO-BRUTO > 7786.02
               MOVE 908.85 TO WS-DESC-INSS
           ELSE
               COMPUTE WS-DESC-INSS ROUNDED = 
                       WS-SALARIO-BRUTO * 0.14
           END-IF.

       2000-CALCULAR-IRRF.
           COMPUTE WS-TOTAL-DED-DEP = 
                   WS-NUM-DEPENDENTES * WS-DED-DEPENDENTE
           
           COMPUTE WS-BASE-IRRF = 
                   WS-SALARIO-BRUTO - WS-DESC-INSS - WS-TOTAL-DED-DEP

           EVALUATE TRUE
               WHEN WS-BASE-IRRF <= 2259.20
                   MOVE 0 TO WS-DESC-IRRF
               WHEN WS-BASE-IRRF <= 2826.65
                   COMPUTE WS-DESC-IRRF ROUNDED = 
                           (WS-BASE-IRRF * 0.075) - 169.44
               WHEN WS-BASE-IRRF <= 3751.05
                   COMPUTE WS-DESC-IRRF ROUNDED = 
                           (WS-BASE-IRRF * 0.15) - 381.44
               WHEN WS-BASE-IRRF <= 4664.68
                   COMPUTE WS-DESC-IRRF ROUNDED = 
                           (WS-BASE-IRRF * 0.225) - 662.77
               WHEN OTHER
                   COMPUTE WS-DESC-IRRF ROUNDED = 
                           (WS-BASE-IRRF * 0.275) - 896.00
           END-EVALUATE.

       3000-CALCULAR-LIQUIDO.
           COMPUTE WS-SALARIO-LIQUIDO = 
                   WS-SALARIO-BRUTO - WS-DESC-INSS - WS-DESC-IRRF.

       4000-EMITIR-HOLERITE.
           MOVE WS-SALARIO-BRUTO   TO WS-ED-BRUTO
           MOVE WS-DESC-INSS       TO WS-ED-INSS
           MOVE WS-DESC-IRRF       TO WS-ED-IRRF
           MOVE WS-SALARIO-LIQUIDO TO WS-ED-LIQUIDO

           DISPLAY "=================================================="
           DISPLAY "           DEMONSTRATIVO DE PAGAMENTO             "
           DISPLAY "=================================================="
           DISPLAY "Matricula: " WS-MATRICULA " | Funcionario: " WS-NOME
           DISPLAY "Cargo:     " WS-CARGO
           DISPLAY "--------------------------------------------------"
           DISPLAY "(+) Salario Bruto ......: " WS-ED-BRUTO
           DISPLAY "(-) Desconto INSS ......: " WS-ED-INSS
           DISPLAY "(-) Desconto IRRF ......: " WS-ED-IRRF
           DISPLAY "--------------------------------------------------"
           DISPLAY "(=) SALARIO LIQUIDO ....: " WS-ED-LIQUIDO
           DISPLAY "==================================================".

       01  WS-TOTALIZADORES.
           05  WS-QTD-LIDOS     PIC 9(06)       VALUE 0.
           05  WS-SOMA-SALDOS   PIC S9(11)V99   VALUE 0.
           05  WS-QTD-CORRENTES PIC 9(06)       VALUE 0.
           05  WS-QTD-POUPANCAS PIC 9(06)       VALUE 0.

       01  WS-ED-SALDO          PIC -ZZZ.ZZZ.ZZ9,99.
       01  WS-ED-TOTAL          PIC -ZZZ.ZZZ.ZZ9,99.

      *>==============================================================*
       PROCEDURE DIVISION.
       0000-PRINCIPAL.
           PERFORM 1000-ABRIR-ARQUIVO
           PERFORM 2000-LER-PRIMEIRO-REGISTRO
           
           PERFORM 3000-PROCESSAR-REGISTRO
               UNTIL FIM-ARQUIVO-SIM
           
           PERFORM 4000-ENCERRAR-RELATORIO
           STOP RUN.

       1000-ABRIR-ARQUIVO.
           OPEN INPUT ARQ-CLIENTES
           IF WS-FS-CLI NOT = "00"
               DISPLAY "ERRO FATAL: Nao foi possivel abrir CLIENTES.DAT"
               DISPLAY "FILE STATUS: " WS-FS-CLI
               STOP RUN
           END-IF
           DISPLAY "------------------------------------------------------------"
           DISPLAY "AG    CONTA     TIPO  NOME CLIENTE                   SALDO"
           DISPLAY "------------------------------------------------------------".

       2000-LER-PRIMEIRO-REGISTRO.
           READ ARQ-CLIENTES
               AT END
                   SET FIM-ARQUIVO-SIM TO TRUE
           END-READ.

       3000-PROCESSAR-REGISTRO.
           ADD 1 TO WS-QTD-LIDOS
           ADD REG-SALDO TO WS-SOMA-SALDOS

           IF REG-TIPO-CONTA = "C"
               ADD 1 TO WS-QTD-CORRENTES
           ELSE
               ADD 1 TO WS-QTD-POUPANCAS
           END-IF

           MOVE REG-SALDO TO WS-ED-SALDO
           DISPLAY REG-AGENCIA "  " 
                   REG-CONTA   "  " 
                   REG-TIPO-CONTA "     " 
                   REG-NOME    " " 
                   WS-ED-SALDO

      *> Leitura do proximo registro
           READ ARQ-CLIENTES
               AT END
                   SET FIM-ARQUIVO-SIM TO TRUE
           END-READ.

       4000-ENCERRAR-RELATORIO.
           CLOSE ARQ-CLIENTES
           MOVE WS-SOMA-SALDOS TO WS-ED-TOTAL
           DISPLAY "------------------------------------------------------------"
           DISPLAY "Total de Registros Lidos .: " WS-QTD-LIDOS
           DISPLAY "Contas Correntes ........: " WS-QTD-CORRENTES
           DISPLAY "Contas Poupanca .........: " WS-QTD-POUPANCAS
           DISPLAY "Saldo Consolidado Geral .: " WS-ED-TOTAL
           DISPLAY "============================================================".

Cálculo financeiro de juros compostos e simulação de parcelas de empréstimo (Tabela Price simplificada) com proteção ON SIZE ERROR e ROUNDED.

       IDENTIFICATION DIVISION.
       PROGRAM-ID. SIMULFIN.
       AUTHOR. PONCE-DEV.
      *>==============================================================*
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01  WS-PARAMETROS-ENTRADA.
           05  WS-VALOR-EMPRESTIMO   PIC 9(07)V99    VALUE 120000.00.
           05  WS-TAXA-ANUAL         PIC 9(02)V99    VALUE 14.50.
           05  WS-PRAZO-MESES        PIC 9(03)       VALUE 48.

       01  WS-VARIAVEIS-CALCULO.
           05  WS-TAXA-MENSAL        PIC 9(02)V9999.
           05  WS-AMORTIZACAO-MES    PIC 9(06)V99.
           05  WS-JUROS-TOTAL        PIC 9(07)V99.
           05  WS-VALOR-TOTAL-PAGO   PIC 9(08)V99.
           05  WS-PARCELA-MEDIA      PIC 9(06)V99.

       01  WS-FORMATACAO.
           05  WS-FMT-EMPRESTIMO     PIC R$*.***.**9,99.
           05  WS-FMT-JUROS          PIC R$*.***.**9,99.
           05  WS-FMT-TOTAL          PIC R$*.***.**9,99.
           05  WS-FMT-PARCELA        PIC R$*.***.**9,99.

      *>==============================================================*
       PROCEDURE DIVISION.
       0000-CALCULAR-FINANCIAMENTO.
           DISPLAY "SIMULADOR DE FINANCIAMENTO BANCARIO - COBOL 2023"
           DISPLAY "------------------------------------------------"

      *> 1. Conversao de taxa anual para taxa mensal estimada
           COMPUTE WS-TAXA-MENSAL ROUNDED = 
                   WS-TAXA-ANUAL / 1200
               ON SIZE ERROR
                   DISPLAY "ERRO: Taxa fora dos limites do sistema!"
                   STOP RUN
           END-COMPUTE

      *> 2. Calculo de juros estimados pelo periodo
           COMPUTE WS-JUROS-TOTAL ROUNDED = 
                   WS-VALOR-EMPRESTIMO * WS-TAXA-MENSAL * WS-PRAZO-MESES
               ON SIZE ERROR
                   DISPLAY "ERRO DE OVERFLOW NO CALCULO DE JUROS"
                   STOP RUN
           END-COMPUTE

      *> 3. Consolidacao do montante final e parcela media
           COMPUTE WS-VALOR-TOTAL-PAGO = 
                   WS-VALOR-EMPRESTIMO + WS-JUROS-TOTAL

           COMPUTE WS-PARCELA-MEDIA ROUNDED = 
                   WS-VALOR-TOTAL-PAGO / WS-PRAZO-MESES

      *> 4. Exibicao dos resultados formatados
           MOVE WS-VALOR-EMPRESTIMO TO WS-FMT-EMPRESTIMO
           MOVE WS-JUROS-TOTAL      TO WS-FMT-JUROS
           MOVE WS-VALOR-TOTAL-PAGO TO WS-FMT-TOTAL
           MOVE WS-PARCELA-MEDIA    TO WS-FMT-PARCELA

           DISPLAY "Valor Principal Contratado : " WS-FMT-EMPRESTIMO
           DISPLAY "Prazo em Meses ...........: " WS-PRAZO-MESES "x"
           DISPLAY "Total de Juros Cobrados ..: " WS-FMT-JUROS
           DISPLAY "------------------------------------------------"
           DISPLAY "VALOR TOTAL A PAGAR ......: " WS-FMT-TOTAL
           DISPLAY "PARCELA MENSAL ESTIMADA ..: " WS-FMT-PARCELA
           DISPLAY "================================================"
           STOP RUN.
