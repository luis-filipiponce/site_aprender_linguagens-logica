🎯 Paradigmas de Programação

Um paradigma é um estilo ou forma de pensar e estruturar o código. A mesma linguagem pode suportar múltiplos paradigmas. Entender paradigmas te faz um programador muito mais versátil e adaptável.

Módulo 5 OOP Funcional Declarativo
1

Programação Imperativa

O estilo mais básico e natural. Você diz ao computador como fazer algo, passo a passo. Usa variáveis, loops e condicionais diretamente. É a forma como nosso cérebro naturalmente pensa em resolver problemas.

# Imperativo: calcular soma de pares de 1 a 100 soma = 0 for i in range(1, 101): if i % 2 == 0: soma += i print(soma) # 2550
2

Orientação a Objetos (OOP)

O paradigma mais usado no mercado. Organiza o código em objetos que combinam dados (atributos) e comportamentos (métodos). O mundo real é modelado como coisas que interagem entre si.

1. Encapsulamento

Esconder os detalhes internos do objeto. Expor apenas o necessário via métodos públicos. Protege o estado interno de modificações externas acidentais.

2. Herança

Uma classe filha herda todos os atributos e métodos da classe pai, podendo estendê-los ou sobrescrevê-los. Promove reutilização de código.

3. Polimorfismo

O mesmo método se comporta de forma diferente em objetos diferentes. Um método falar() age diferente em Cachorro e em Gato, mesmo chamado da mesma forma.

4. Abstração

Simplificar a realidade, expondo apenas o essencial e escondendo a complexidade interna. Você usa um carro sem saber como o motor funciona internamente.

# OOP completo — sistema bancário class Conta: def __init__(self, titular: str, saldo: float = 0.0): self.titular = titular self.__saldo = saldo # __ = privado (encapsulamento) def depositar(self, valor: float): if valor <= 0: raise ValueError("Valor deve ser positivo") self.__saldo += valor def sacar(self, valor: float): if valor > self.__saldo: raise ValueError("Saldo insuficiente") self.__saldo -= valor @property def saldo(self): return self.__saldo # leitura controlada def __repr__(self): return f"Conta({self.titular!r}, saldo=R${self.__saldo:.2f})" class ContaPoupanca(Conta): # herança def __init__(self, titular, taxa=0.005): super().__init__(titular) self.taxa = taxa def render_juros(self): # método específico da subclasse juros = self.saldo * self.taxa self.depositar(juros) return juros cc = Conta("Ana") cc.depositar(1000) cc.sacar(200) print(cc) # Conta('Ana', saldo=R$800.00) cp = ContaPoupanca("Carlos") cp.depositar(5000) print(cp.render_juros()) # 25.0
3

Programação Funcional

Trata a computação como avaliação de funções matemáticas puras. Evita estado mutável e efeitos colaterais. Funções são "cidadãs de primeira classe" — podem ser passadas como argumentos e retornadas como valores.

Função pura: Dado o mesmo input, sempre retorna o mesmo output. Não modifica estado externo. É previsível, testável e paralelizável.
# Funcional em Python # map — aplica função a cada elemento nomes = ["ana", "carlos", "beatriz"] maiusculos = list(map(str.upper, nomes)) print(maiusculos) # ['ANA', 'CARLOS', 'BEATRIZ'] # filter — filtra elementos numeros = [1, 2, 3, 4, 5, 6, 7, 8] pares = list(filter(lambda x: x % 2 == 0, numeros)) print(pares) # [2, 4, 6, 8] # reduce — agrega em um único valor from functools import reduce produto = reduce(lambda acc, x: acc * x, [1,2,3,4,5]) print(produto) # 120 # Composição de funções def compor(*fns): def composta(x): for fn in reversed(fns): x = fn(x) return x return composta processar = compor(str.upper, str.strip) print(processar(" python ")) # "PYTHON"
4

Programação Declarativa

Você diz o que quer, não como fazer. O sistema descobre a melhor forma de executar. SQL é o exemplo clássico — você descreve o resultado desejado e o banco faz o trabalho duro.

-- SQL — puramente declarativo -- Você diz O QUÊ quer, não COMO buscar SELECT departamento, AVG(salario) AS media_salarial, COUNT(*) AS total_funcionarios FROM funcionarios WHERE ativo = TRUE GROUP BY departamento HAVING AVG(salario) > 5000 ORDER BY media_salarial DESC;
5

Mesmo problema, paradigmas diferentes

Para ilustrar, vamos resolver o mesmo problema (somar números pares de 1 a 10) nos três paradigmas:

# 1. IMPERATIVO — diz como fazer soma = 0 for i in range(1, 11): if i % 2 == 0: soma += i # 2. FUNCIONAL — diz o que transformar from functools import reduce soma = reduce(lambda a,b: a+b, filter(lambda x: x%2==0, range(1,11))) # 3. DECLARATIVO (Python moderno) soma = sum(x for x in range(1, 11) if x % 2 == 0) print(soma) # 30 nos três casos
