Como a Web Funciona

Quando você digita uma URL no browser e aperta Enter, uma cadeia precisa de eventos acontece em milissegundos:

1. Você digita: https://www.google.com 2. DNS Lookup — Quem é google.com? Browser → DNS Server → responde: 142.250.80.46 3. TCP Handshake — Conectar ao servidor Browser → Servidor: SYN Servidor → Browser: SYN-ACK Browser → Servidor: ACK ✅ Conectado! 4. TLS Handshake (HTTPS) — Criptografar tudo Troca de certificados e chave de sessão 5. Requisição HTTP GET / HTTP/2 Host: www.google.com Accept: text/html 6. Resposta HTTP HTTP/2 200 OK Content-Type: text/html [corpo HTML da página] 7. Browser renderiza HTML + CSS + executa JavaScript

HyperText Markup Language. Define o conteúdo e estrutura da página usando elementos (tags). O esqueleto da web.

CSS — Estilo

Cascading Style Sheets. Define a aparência visual: cores, fontes, espaçamentos, layouts e animações.

/* CSS moderno — Flexbox e Grid */ .container { display: flex; justify-content: space-between; align-items: center; gap: 16px; } .grid-layout { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; } /* Responsividade com media queries */ @media (max-width: 768px) { .grid-layout { grid-template-columns: 1fr; } } /* Variáveis CSS */ :root { --cor-primaria: #3b82d4; --fonte: "Segoe UI", sans-serif; } body { color: var(--cor-primaria); font-family: var(--fonte); }

Back-end — O Que Roda no Servidor

O back-end processa a lógica de negócio, acessa bancos de dados, autentica usuários e serve dados ao front-end. O usuário nunca vê o back-end diretamente.

API REST com Python (FastAPI)

from fastapi import FastAPI, HTTPException from pydantic import BaseModel app = FastAPI() class Produto(BaseModel): nome: str preco: float banco_fake = [ {"id": 1, "nome": "Notebook", "preco": 3500.0}, {"id": 2, "nome": "Mouse", "preco": 89.90}, ] @app.get("/produtos") def listar_produtos(): return banco_fake @app.get("/produtos/{id}") def buscar_produto(id: int): p = next((x for x in banco_fake if x["id"] == id), None) if not p: raise HTTPException(404, "Produto não encontrado") return p @app.post("/produtos", status_code=201) def criar_produto(produto: Produto): novo = {"id": len(banco_fake)+1, **produto.dict()} banco_fake.append(novo) return novo

Desenvolvimento Mobile

📱 Android Nativo (Kotlin)

Linguagem oficial do Android desde 2017. Acesso total a todos os recursos do dispositivo. Deploy na Play Store.

🍎 iOS Nativo (Swift)

Linguagem da Apple desde 2014. Obrigatório para publicar na App Store. Melhor performance no ecossistema Apple.

⚛️ React Native

Um código JavaScript/TypeScript para Android e iOS. Desenvolvido pelo Meta. Base grande de devs JS no mercado.

🐦 Flutter (Dart)

Framework do Google. Linguagem Dart. Performance próxima ao nativo. UI consistente em todas as plataformas.

Cross-platform vs Nativo: Apps nativos têm melhor performance e integração com o dispositivo. Apps cross-platform (React Native, Flutter) economizam tempo — um time, dois sistemas operacionais.
