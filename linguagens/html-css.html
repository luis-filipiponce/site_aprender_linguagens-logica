História & Evolução

De um simples formato de documentos científicos no CERN até as plataformas ricas e responsivas de hoje: veja como HTML e CSS evoluíram em paralelo.

🧱 HTML <html>

1991
HTML 1.0

Criado por Tim Berners-Lee no CERN, com cerca de 18 tags para compartilhar documentos.

1995
HTML 2.0

Primeira especificação padronizada (IETF), incluindo formulários.

1997
HTML 4.0

Folhas de estilo, scripts, frames e melhor suporte à acessibilidade e internacionalização.

2000
XHTML

HTML reformulado como XML: sintaxe mais rígida e bem formada.

2014
HTML5 — a revolução

Semântica (header, article), video/audio, canvas e dezenas de APIs (Storage, Geolocation, Drag & Drop).

🎨 CSS { }

1994
CSS proposto

Håkon Wium Lie propõe as Cascading Style Sheets para separar conteúdo de apresentação.

1996
CSS1

Recomendação oficial do W3C: fontes, cores, margens e texto.

1998
CSS2

Posicionamento absoluto/relativo, z-index, mídia e seletores avançados.

2011
CSS3

Dividido em módulos independentes: bordas arredondadas, sombras, transições, Flexbox, Media Queries.

2020+
CSS moderno

CSS Grid, Custom Properties, Container Queries, :has() e Cascade Layers.

Conceitos Fundamentais

Clique em cada tópico para ver a explicação e um exemplo de código.

Todo elemento é uma caixa composta por quatro camadas: content (conteúdo), padding (espaço interno), border (borda) e margin (espaço externo). Use box-sizing: border-box para que largura e altura incluam padding e borda.

css
*, *::before, *::after {
  box-sizing: border-box;
}

.caixa {
  width: 300px;          /* content + padding + border */
  padding: 20px;         /* espaço interno */
  border: 2px solid #f97316;
  margin: 16px auto;     /* espaço externo, centralizado */
}

Layout unidimensional baseado em dois eixos: o eixo principal (justify-content) e o eixo cruzado (align-items). Ideal para barras de navegação, alinhamentos e distribuição de espaço.

css
.navbar {
  display: flex;
  flex-direction: row;            /* define o eixo principal */
  justify-content: space-between; /* alinha no eixo principal */
  align-items: center;            /* alinha no eixo cruzado */
  gap: 16px;
}

.navbar .busca { flex: 1; }       /* ocupa o espaço restante */

Sistema de layout bidimensional: você define linhas e colunas e posiciona os itens nelas. Com repeat(), minmax() e fr, criar grades responsivas fica simples.

css
.galeria {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  grid-template-rows: auto;
  gap: 20px;
}

.destaque {
  grid-column: span 2;   /* ocupa 2 colunas */
}

Seletores escolhem quais elementos receberão estilo. Quando há conflito, vence a regra de maior especificidade: inline (1000) > ID (100) > classe/atributo/pseudo-classe (10) > elemento (1). Em empate, vale a última declarada.

css
p                { color: black; }   /* 0-0-1 */
.destaque        { color: blue;  }   /* 0-1-0 */
p.destaque       { color: green; }   /* 0-1-1 */
#principal       { color: red;   }   /* 1-0-0 */

a[target="_blank"]::after { content: " ↗"; }
li:nth-child(odd)         { background: #f3f3f3; }
.card:has(img)            { padding: 0; }

Variáveis nativas declaradas com --nome e lidas com var(). Diferente de variáveis de pré-processadores, elas existem em tempo de execução e podem ser alteradas via JavaScript ou em media queries — perfeitas para temas.

css
:root {
  --cor-primaria: #f97316;
  --espaco: 1rem;
}

[data-tema="escuro"] {
  --cor-fundo: #111;
  --cor-texto: #eee;
}

.botao {
  background: var(--cor-primaria);
  padding: var(--espaco, 8px); /* valor de fallback */
}

Com a abordagem mobile-first, você escreve o estilo base para telas pequenas e usa @media (min-width) para melhorar em telas maiores. Não esqueça a meta tag viewport.

html + css
<meta name="viewport" content="width=device-width, initial-scale=1">

/* Mobile first */
.container { padding: 16px; }
.colunas   { display: grid; grid-template-columns: 1fr; }

@media (min-width: 768px) {
  .colunas { grid-template-columns: repeat(2, 1fr); }
}
@media (min-width: 1100px) {
  .colunas { grid-template-columns: repeat(3, 1fr); }
}
@media (prefers-color-scheme: dark) {
  body { background: #111; color: #eee; }
}

Dashboard responsivo com CSS Grid

Usamos grid-template-areas para nomear regiões do layout. No celular tudo empilha; no desktop surge a barra lateral.

html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Dashboard</title>
  <style>
    *, *::before, *::after { box-sizing: border-box; }
    body { margin: 0; font-family: system-ui, sans-serif; background: #f4f4f5; }

    .dashboard {
      display: grid;
      min-height: 100vh;
      gap: 16px;
      padding: 16px;
      grid-template-areas:
        "header"
        "stats"
        "chart"
        "sidebar"
        "footer";
    }
    .dashboard > * {
      background: #fff;
      border-radius: 12px;
      padding: 20px;
      box-shadow: 0 1px 4px rgba(0,0,0,.08);
    }
    .header  { grid-area: header; }
    .stats   { grid-area: stats; display: grid;
               grid-template-columns: repeat(auto-fit, minmax(140px, 1fr)); gap: 12px; }
    .chart   { grid-area: chart; min-height: 220px; }
    .sidebar { grid-area: sidebar; }
    .footer  { grid-area: footer; text-align: center; }

    .stat strong { display: block; font-size: 1.8rem; color: #f97316; }

    @media (min-width: 900px) {
      .dashboard {
        grid-template-columns: 240px 1fr 1fr;
        grid-template-rows: auto auto 1fr auto;
        grid-template-areas:
          "header  header header"
          "sidebar stats  stats"
          "sidebar chart  chart"
          "footer  footer footer";
      }
    }
  </style>
</head>
<body>
  <div class="dashboard">
    <header class="header"><h1>Painel de Vendas</h1></header>
    <section class="stats" aria-label="Indicadores">
      <div class="stat"><strong>1.248</strong>Pedidos</div>
      <div class="stat"><strong>R$ 48k</strong>Receita</div>
      <div class="stat"><strong>96%</strong>Satisfação</div>
    </section>
    <section class="chart"><h2>Vendas por mês</h2></section>
    <aside class="sidebar">
      <nav aria-label="Menu">
        <ul><li>Início</li><li>Relatórios</li><li>Configurações</li></ul>
      </nav>
    </aside>
    <footer class="footer">© 2025 Minha Empresa</footer>
  </div>
</body>
</html>

Componente Card animado com :hover e transitions

Elevação, zoom suave na imagem e revelação do botão — tudo apenas com CSS. O bloco prefers-reduced-motion respeita usuários sensíveis a movimento.

html + css
<article class="card">
  <div class="card__media">
    <img src="https://picsum.photos/600/400" alt="Paisagem de montanhas ao amanhecer">
  </div>
  <div class="card__body">
    <span class="card__tag">Tutorial</span>
    <h3 class="card__title">Dominando CSS Grid</h3>
    <p>Aprenda a criar layouts complexos com poucas linhas de código.</p>
    <a class="card__btn" href="#">Ler mais →</a>
  </div>
</article>

<style>
  .card {
    --raio: 16px;
    max-width: 340px;
    background: #fff;
    border-radius: var(--raio);
    overflow: hidden;
    box-shadow: 0 2px 8px rgba(0,0,0,.1);
    transition: transform .3s ease, box-shadow .3s ease;
  }
  .card:hover,
  .card:focus-within {
    transform: translateY(-8px);
    box-shadow: 0 16px 32px rgba(249,115,22,.25);
  }

  .card__media { overflow: hidden; aspect-ratio: 3 / 2; }
  .card__media img {
    width: 100%; height: 100%; object-fit: cover;
    transition: transform .5s ease;
  }
  .card:hover .card__media img { transform: scale(1.08); }

  .card__body { padding: 20px; }
  .card__tag {
    display: inline-block; padding: 2px 10px; border-radius: 999px;
    background: #fff1e6; color: #c2410c; font-size: .75rem; font-weight: 700;
  }
  .card__title { margin: 10px 0 6px; }

  .card__btn {
    display: inline-block; margin-top: 8px;
    color: #f97316; font-weight: 700; text-decoration: none;
    opacity: .6; transform: translateX(-6px);
    transition: opacity .3s, transform .3s;
  }
  .card:hover .card__btn,
  .card__btn:focus-visible { opacity: 1; transform: translateX(0); }

  /* Animação com keyframes: entrada do card */
  @keyframes surgir {
    from { opacity: 0; transform: translateY(24px); }
    to   { opacity: 1; transform: translateY(0); }
  }
  .card { animation: surgir .6s ease both; }

  @media (prefers-reduced-motion: reduce) {
    .card, .card * { animation: none; transition: none; }
  }
</style>

Formulário acessível com validação nativa HTML5

Sem JavaScript: required, type="email", pattern e minlength fazem a validação. Rótulos associados, aria-describedby e as pseudo-classes :user-invalid/:focus-visible melhoram a experiência.

html + css
<form class="form" action="/inscricao" method="post">
  <fieldset>
    <legend>Inscrição no curso</legend>

    <div class="campo">
      <label for="nome">Nome completo *</label>
      <input id="nome" name="nome" type="text" required minlength="3"
             autocomplete="name" aria-describedby="nome-ajuda">
      <small id="nome-ajuda">Mínimo de 3 caracteres.</small>
    </div>

    <div class="campo">
      <label for="email">E-mail *</label>
      <input id="email" name="email" type="email" required
             autocomplete="email" placeholder="voce@exemplo.com">
    </div>

    <div class="campo">
      <label for="tel">Telefone</label>
      <input id="tel" name="tel" type="tel" autocomplete="tel"
             pattern="\(\d{2}\) \d{4,5}-\d{4}" placeholder="(11) 91234-5678"
             aria-describedby="tel-ajuda">
      <small id="tel-ajuda">Formato: (11) 91234-5678</small>
    </div>

    <div class="campo">
      <label for="nivel">Nível de experiência</label>
      <select id="nivel" name="nivel" required>
        <option value="">Selecione…</option>
        <option value="iniciante">Iniciante</option>
        <option value="intermediario">Intermediário</option>
        <option value="avancado">Avançado</option>
      </select>
    </div>

    <div class="campo campo--check">
      <input id="termos" name="termos" type="checkbox" required>
      <label for="termos">Li e aceito os termos de uso *</label>
    </div>

    <button type="submit">Enviar inscrição</button>
  </fieldset>
</form>

<style>
  .form { max-width: 460px; font-family: system-ui, sans-serif; }
  fieldset { border: 1px solid #d4d4d8; border-radius: 12px; padding: 20px; }
  legend { font-weight: 700; padding: 0 8px; }
  .campo { display: flex; flex-direction: column; gap: 4px; margin-bottom: 16px; }
  .campo--check { flex-direction: row; align-items: center; gap: 8px; }
  label { font-weight: 600; }
  small { color: #52525b; }

  input:not([type="checkbox"]), select {
    padding: 10px 12px;
    border: 2px solid #d4d4d8;
    border-radius: 8px;
    font: inherit;
    transition: border-color .2s, box-shadow .2s;
  }
  input:focus-visible, select:focus-visible, button:focus-visible {
    outline: 3px solid #fdba74;
    outline-offset: 2px;
    border-color: #f97316;
  }
  input:user-invalid, select:user-invalid { border-color: #dc2626; }
  input:user-valid { border-color: #16a34a; }

  button[type="submit"] {
    width: 100%; padding: 12px; border: 0; border-radius: 8px;
    background: #f97316; color: #fff; font: inherit; font-weight: 700; cursor: pointer;
    transition: background .2s;
  }
  button[type="submit"]:hover { background: #ea580c; }
</style>
